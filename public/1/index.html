yggdrasil network and what it means for you

Yggdrasil network is a network consisting of computers, each given an address in the 200::/7 space and reachable using tcp/tls. In order to set up peers on another network, you must establish a clearnet connection to the peer. This usually is done over ipv6, almost always indepent of BGP. ( big goopy protocol, aka border gateway protocol, I'll talk more about it later ) This does mean that any device without port forwarding or global ipv6 (ahem, frontier) can't be a public node. You should use Yggdrasil Network because it is encrypted, peer to peer (other than the first step of connecting to the first peer, all hops after are over yggdrasil), and scalable up to big sizes. BGP requires shitloads of compute to route and is very bloated, so please use yggdrasil, i2p or anything better.
