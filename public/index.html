Peranti:

Hi all! I have been working on a project known as Peranti. It is a custom triangle renderer for luanti, which means it make shape go on screen. It doesn't have any custom functionality yet, just a layer that lets sokol_gfx (my rendering library of choice) interact with IrrlichMt's (luanti's base renderer) OpenGL (widely used gpu interactor) instance, letting me draw custom geometry.
